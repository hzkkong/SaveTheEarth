<h2>3차 프로젝트 환경 보호 체험 메타버스 플랫폼</h2>

<h3>Team.지구방범대</h3>

팀장 공혜지

공혜지(Unity), 김준성(Unity), 박진영(Unity), 김은설(AI)

제작 기간 : 2024.08.26 ~ 2024.09.27

제작툴: Unity URP, Photon, Blender

캐릭터 및 오브젝트 데이터: Unity Asset Store

프로젝트 개요 : 지구지키미는 가상의 메타버스 공간에서 유저가 환경보전과 관련된 미션을 해결해나가며 환경의 중요성을 체험하고 학습할 수 있도록 기획했습니다. 유저는 실제로 환경보전에 기여할 수 있는 실질적인 챌린지(대중교통 이용, 텀블러 사용)를 함께 수행해 나가며, 이를 통해 유저에게 가상과 현실을 연계한 환경보전의 의미를 깨닫게 하고, 지속 가능한 실천으로 연결하는 것을 목표로 했습니다.

공혜지: Photon 관리, AI 챗봇 클라이언트 연동 시스템
